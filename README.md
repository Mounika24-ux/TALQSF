# TALQS - Transformer-based Architecture for Legal Question Answering and Summarization

## Overview
TALQS is an AI-powered legal document analysis system that generates summaries and answers questions from legal judgments using Transformer models.

## Features
- Legal document summarization
- Question Answering on legal texts
- NLP-based preprocessing
- User-friendly web interface

## Tech Stack
- Python
- PyTorch
- Hugging Face Transformers
- FastAPI
- React.js
- Node.js
- MongoDB

## Dataset
- 500+ legal documents
- NLP preprocessing and tokenization
